Управление таблицами

Синтаксис команд:
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ... создать таблицу.
drop_table <имя_таблицы> удалить таблицу.
list_tables показать список всех таблиц.
help показать справку.
exit выйти.
Поддерживаемые типы данных: int, str, bool.

CRUD-операции

Программа поддерживает добавление, просмотр, изменение и удаление записей в таблицах.

Добавление записи

>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

Команда добавляет новую запись в таблицу users. ID создаётся автоматически.

Просмотр всех записей

>>> Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

Команда выводит все записи таблицы.

Просмотр записей по условию

select from users where age = 28

Команда выводит записи, соответствующие условию.

Изменение записи

>>> Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

Команда изменяет возраст пользователя.

Удаление записи

>>> Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

Команда удаляет запись с указанным ID.

>>> Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0 

Хранение данных

Структура таблиц сохраняется в файле db_meta.json.

Данные каждой таблицы сохраняются в отдельном JSON-файле в папке data.

Для вывода записей используется библиотека PrettyTable.

В проект добавлен модуль src/primitive_db/decorators.py.

Обработка ошибок

Декоратор handle_db_errors перехватывает ошибки:

* FileNotFoundError — файл не найден.
* KeyError — таблица или столбец не найден.
* ValueError — некорректные данные.

Подтверждение удаления

Декоратор confirm_action запрашивает подтверждение перед удалением таблицы или записей.

Ответ y разрешает операцию. Любой другой ответ отменяет её.

Измерение времени

Декоратор log_time измеряет время выполнения операций insert и select с помощью time.monotonic().

Кэширование

Функция create_cacher() создаёт замыкание со словарём для хранения результатов.
